# Data inputs

`marker/` contains the small ancestry-marker frequency tables used by `R/01_marker_ancestry.R`.

The Illumina read-count file used by `R/02_illumina_ancestry.R` is not included here. The script expects the tab-delimited `readcount_by_bottle_Illumina_data` file produced from the generation-46 sequencing analysis.

SLiM output is generated locally under `results/simulations/` by the shell scripts.
